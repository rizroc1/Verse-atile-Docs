# Security Policy

## Public documentation repository

This repository contains public documentation only and must not contain private Verse-atile source code, credentials, private Unreal assets, or confidential security material.

## Reporting security concerns

Do not publish secrets, credentials, private user data, or weaponized exploit details in a public issue.

A private security-reporting channel will be documented here before public release of features that require one.

## Supply-chain and provenance

Public third-party references must preserve applicable licenses and attribution. Security-sensitive dependencies and downloads must follow Verse-atile Guardian provenance, integrity, and validation rules before they are recommended for production use.
