# Community Feedback & Feature Requests

Community input will help prioritize usability improvements, documentation, presets, compatibility work, and future features.

Planned public channels include:

- Feature requests
- Beginner usability feedback
- Bug reports
- Hardware/compatibility reports
- Documentation requests
- Preset requests
- General discussion

Community feedback informs recommendations; it does not automatically override security, rights, compatibility, validation, or product-owner decisions.
