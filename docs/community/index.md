# Community Feedback & Feature Voting

Verse-atile is designed to grow with structured community feedback while keeping security, rights, compatibility, validation, and product-owner decisions authoritative.

[Take the Survey / General Feedback](https://github.com/rizroc1/Verse-atile-Docs/issues/new?template=survey_feedback.yml){ .md-button }

[Report a Bug](https://github.com/rizroc1/Verse-atile-Docs/issues/new?template=bug_report.yml){ .md-button }

[Share a Hardware / Compatibility Report](https://github.com/rizroc1/Verse-atile-Docs/issues/new?template=hardware_compatibility.yml){ .md-button }

These forms are public. Never submit private Verse-atile source code, credentials, account data, private project files, serial numbers, IP addresses, or confidential material.

## Feature voting and polls

Public feature-voting issues use a simple rule:

- Read the proposal and compatibility/security notes first.
- Use 👍 to support a proposal you would genuinely use.
- Add a comment when you can explain the workflow or problem the feature would solve.
- Do not create duplicate votes or spam campaigns.

Votes are **signals, not automatic roadmap authority**. A popular request can still be blocked by safety, rights, Unreal compatibility, performance, dependencies, or validation requirements.

Formal multi-option polls may also be posted by the Verse-atile project owner. Each poll will explain exactly how votes are counted.

## Discord

Discord is planned as an **optional community provider**, not the only place where Verse-atile information lives.

The intended Discord integration can provide:

- release and update announcements
- documentation links
- survey and feature-request links
- community polls
- known-issue/status announcements
- optional support/community channels

Native Discord webhooks or a first-party Verse-atile community bot can be used. MEE6 may also be used for polls, moderation, or automations where its current permissions and plan fit the need, but Verse-atile will not depend on MEE6.

A public Discord invite will be added here only after the official server is created and approved. Bot tokens and webhook URLs are secrets and will never be committed to this public repository.

## How community feedback is used

The long-term feedback pipeline is designed to sanitize, deduplicate, classify and aggregate public reports, detect trends, separate popularity from severity, and produce evidence-backed recommendations. It does **not** let a poll silently rewrite Verse-atile or change the roadmap automatically.
