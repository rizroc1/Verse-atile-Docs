# Privacy, Permissions & Data

Verse-atile's public direction is **explicit permission, least privilege, and revocable access**.

Future integrations such as local-computer automation or cloud storage must clearly explain:

- What access is requested
- Why it is needed
- Which files/folders/providers are in scope
- What data leaves the computer
- How access can be revoked

This public documentation website does not request access to local Unreal projects or Google Drive.

Credentials, tokens, private files, user data, and private production source are not published here.
