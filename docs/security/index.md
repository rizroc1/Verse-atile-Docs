# Security

Security documentation will cover safe downloads, integrity verification, permissions, provider trust, and public security-reporting guidance as workflows become release-ready.

## Public repository boundary

This repository must not contain:

- Verse-atile private production source code
- Private Unreal projects or assets
- API keys or tokens
- Passwords or credentials
- Private receipts or logs
- Private customer/user data
- Proprietary unreleased assets
