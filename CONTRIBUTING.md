# Contributing to Verse-atile Public Documentation

Thank you for helping improve the public Verse-atile documentation.

## Public-only contributions

Do not submit:

- private Verse-atile production source code
- private Unreal project files or assets
- credentials, API keys, OAuth tokens, passwords, or certificates
- private receipts, internal logs, machine inventories, or confidential evidence
- third-party material without clear redistribution rights
- proprietary material copied from another product
- security-sensitive exploit details that should be privately reported

## Documentation contributions

Useful public contributions may include:

- typo and clarity fixes
- tutorials
- public examples
- compatibility reports
- hardware observations
- feature documentation feedback
- accessibility improvements
- translations when approved
- corrections to public credits/attributions with supporting evidence

By submitting content, the contributor must have the right to submit it and must identify third-party material and its applicable license where relevant.

No contribution automatically changes the private Verse-atile software license or ownership.
